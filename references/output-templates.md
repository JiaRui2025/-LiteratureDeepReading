# 输出模板（直接套用）

六个模板对应：路线图 / 单元带读 / 全文总结 / 中文笔记 / 英文笔记 / 追问回答。**照抄结构，替换内容**，不自创排版。

---

## 模板 A · 阅读路线图（Stage 0）

```markdown
# 阅读路线图｜《论文标题》

| 项目 | 内容 |
|---|---|
| 作者 / 机构 | … |
| 年份 · 出处 | 2026 · 期刊 卷(期): 页码，doi: … |
| 文献类型 | 实验型 / 综述 / 理论 / 案例 / 方法 / 立场评论 |
| 研究问题 | 一句话 |
| 一句话结论 | 作者的答案 |

## 全文结构

| 单元 | 论证环节 | 覆盖章节 | 页码 | 该单元回答的问题 |
|---|---|---|---|---|
| 1 | 问题与缺口 | Abstract + Introduction | p.1–2 | 为什么值得研究？前人漏了什么？ |
| 2 | 证据 | 配方 + 表征 + 主结果 | p.2–3 | 数据站得住吗？ |
| 3 | 机制 | 演化 + 类比 | p.4–5 | 为什么会这样？ |
| 4 | 含义 | 工程对比 + 应用边界 | p.5 | 能用到哪里？ |
| 5 | 可复现性 | Materials and Methods | p.5–6 | 别人能重做吗？ |

**共 5 个阅读单元。**

## 阅读提示

1. …（数据或排版问题）
2. …（SI 缺失、不可核验处）
3. …（利益关系或与相关文献的关系）

路线图如上。回复「继续」开始 **单元 1（…，p.1）**。
```

**要求**：论证环节一列写"这一单元回答什么问题"，不写章节名复述；阅读提示 2–4 条，只写影响可信度或阅读方式的。

## 模板 B · 单元带读（Stage 1）

```markdown
## §3.2 训练目标（p.5–6）

**定位**：本节回答"模型如何被优化"，为 §4 的实验提供训练协议。

**解读**

- **损失函数**：用序列级似然（sequence-level likelihood）替代逐词交叉熵（token-level cross-entropy）。
- **正则化**：dropout 0.1 + 标签平滑（label smoothing）ε = 0.1。
- **优化**：AdamW，warmup 4000 steps + 余弦退火（cosine decay）。

**要点**

1. **训练目标是序列级似然最大化** —— 损失对整句结构敏感而非逐词对齐，长句连贯性因此受益，但逐词可控性下降。
2. **正则化只靠 label smoothing（ε=0.1），未做敏感性分析** —— 该系数是否最优无从判断，复现时需自行调参。
3. **调度策略在 §4.3 被单独验证** —— 说明作者视其为关键变量，训练稳定性部分依赖这一设定。

**精读**

- ⚠️ 公式 (3) 的求和范围未注明是否含 `<eos>`，影响复现。
- 仅 1 组随机种子（seed=42），"训练稳定"的证据强度有限。

**术语**

| 英文 / 缩写 | 中文 | 本文语境 |
|---|---|---|
| sequence-level likelihood | 序列级似然 | 训练目标 |
| label smoothing | 标签平滑 | 正则化手段 |
| warmup | 预热 | 学习率爬升阶段 |

---

本部分完。回复「继续」进入 §3.3 实现细节（p.6）。
```

**要点提示**

- 五节固定：定位 / 解读 / 要点 / 精读 / 术语。不设「承上启下」，衔接写进结尾一句。
- 解读用 `- **短标签**：内容` 紧凑列表，每块 1–3 句；不用 `**第 n 段｜**` 分块。
- 要点 3 条，每条 1–2 句，必须是**结论 + 含义**。禁止"XXX 很重要"式空转，禁止名词短语。
- 精读 2–3 条，只写非显而易见处与 ⚠️ 可疑处。
- 术语 ≤6 行，可整节省略。
- 正文 600–900 中文字（表格不计）。

## 模板 E · 英文笔记（用户要求时）

文件名：`<Title_Keywords>_Reading_Notes_EN.md`。

- 结构与模板 D **一一对应**，节号一致。
- 数值、单位、页码不变。
- 用英文学术惯例表述，多用 hedged 措辞：*appears to*、*the evidence does not support*、*this remains unverified*。
- Glossary 改为释义式（Term | Meaning in this paper），不做中英对照。
- 关键句保留英文原文，页码不变。
- **不逐句直译**：中文版里的判断句在英文版中应重写为对应的学术表达，而非字面翻译。

## 模板 F · 追问回答（Stage 3）

```markdown
## 直接回答
一句话：是 / 否 / 部分，以及限定条件。

## 证据

| 指标 | 数据 | 页码 |
|---|---|---|

## 判断
这些证据能支持到哪一步；哪一步超出数据。

## 论文没做的部分
- 未测 …
- 未分离 …
- 未覆盖 …
```

**要求**：跨节问题必须回原文取数，不凭记忆；若涉及作者未讨论的推论，明确写"这是我的推断，原文未展开"。
