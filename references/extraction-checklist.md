# 抽取清单与常见陷阱

带读前先判定文献类型，按下表确定每个部分「该抓什么」。不适用则跳过，不硬套。

---

## 1. 通用骨架（所有类型）

| 章节 | 必须抓到 |
|---|---|
| Abstract | 研究问题、方法一句话、主要结论、声称的贡献 |
| Introduction | 背景缺口（gap）、研究问题/假设、贡献清单 |
| Method | 输入与输出、关键假设、流程、可复现所需的参数 |
| Results | 数据表、基线、指标、显著性、异常值 |
| Discussion | 结果解释、与假设的一致性、意外发现 |
| Conclusion | 作者自陈的贡献、未来工作 |
| Limitations / SI | 常藏最关键的局限与实现细节，**不可跳过** |

**横向核查（贯穿全文）**：摘要声称是否被正文数据支撑；贡献清单是否逐条兑现；图表与正文数字是否一致。

## 2. 分类型重点

### 实验 / 实证（Experimental / Empirical）

- 研究设计与识别策略：随机对照、准实验、观测
- 样本：来源、规模、筛选标准、代表性
- 变量与测量：自变量、因变量、控制变量、量测方法
- 统计：模型、效应量、置信区间、p 值、多重比较校正
- 因果边界：是否把相关说成因果

### 材料 / 保护科学（Materials / Conservation Science）

- 试样是**真实对象还是模拟样**：模拟样的孔隙率、胶结状态、盐含量是否与真实对象一致
- 配比与工艺：比例是质量比还是体积比、拌合水、养护温湿度、成型方式
- 表征手段的分辨率与适用边界：XRD / FTIR / SEM-EDS / CT / 同步辐射，各自能证明什么、不能证明什么
- **相归属是否有直接证据**：FTIR 的通用谱带不足以定相，需 XRD 或电子衍射
- 性能指标是否互证：强度、韧性、孔隙率、渗透率、吸水、耐蚀是否同向
- 耐久性试验：有无冻融、干湿、盐循环、紫外、SO₂；单次试验不能代表长期
- 与既有材料的对照是否同条件

### 综述 / 元分析（Review / Meta-analysis）

- 检索策略：数据库、关键词、时间窗、纳入/排除标准（有无 PRISMA）
- 纳入文献数与质量评价方法
- 分类框架（taxonomy）：用什么维度组织文献
- 共识与分歧：哪些结论一致，哪些互相矛盾
- 元分析额外看：异质性（I²）、发表偏倚、合并效应量
- **叙事性综述**：无检索策略时，须指出"这是作者概括，不是系统证据"

### 理论 / 建模（Theoretical / Modeling）

- 核心假设与前设
- 形式化定义与推导链：每步是否可验证
- 命题成立条件与边界
- 与已有理论的对话：修正了什么、放弃了什么

### 案例研究（Case Study）

- 案例选择理由、单案例还是多案例
- 数据来源与三角验证（triangulation）
- 分析单位与编码过程
- 外部效度：能否推广，作者如何论证

### 方法 / 系统 / 算法（Methods / Systems）

- 问题形式化
- 架构与算法细节、复杂度、伪代码
- 实验设置：数据划分、超参搜索范围、计算资源
- 基线是否强、是否公平调参、指标是否恰当
- 消融是否支撑各模块必要性
- 可复现性：代码与数据是否公开

### 立场 / 评论（Position / Commentary）

- 核心主张与论证结构（而非数据）
- 反驳对象与反驳逻辑
- 作者立场与潜在利益关系

## 3. 常见陷阱

读到对应位置时主动提示，措辞中性，给依据与页码。

| 陷阱 | 识别信号 | 带读时怎么说 |
|---|---|---|
| 摘要夸大 | 结论强度 > 数据支撑 | "摘要称 X，正文仅支持较弱的 Y（p.7）。" |
| 基线偏弱 | 基线未调参 / 用旧版本 | "基线 A 用 2019 年设定，与本文不可比。" |
| 选择偏倚 | 样本单一或自选 | "样本来自单一机构，外部效度受限。" |
| 幸存者偏差 | 只研究"还存在的"对象 | "残存组本身是筛选结果，早期倒塌者不在样本内。" |
| 多重比较未校正 | 多指标只报显著的 | "共检验 12 组，仅 3 组显著且未校正。" |
| 变量共变 | 两个因素同步变化 | "温度与 RH 同步改变，归因于其一是假设。" |
| 相关当因果 | 观测数据用因果措辞 | "作者用'导致'，设计只支持'相关'。" |
| 坐标轴截断 | 纵轴不从 0 起 | "图 3 纵轴截断，差异被放大。" |
| 分辨率不足 | 结论差异 ≈ 仪器精度 | "差异 0.01 个百分点，分辨率约 0.006%，不显著。" |
| n = 1 却下结论 | 关键测试无重复 | "MIP 每组 1 个试件，结论无统计支撑。" |
| 单位误排 | 量级异常 | "7,320 GPa 对混凝土高三个数量级，疑为 MPa。" |
| 相归属证据不足 | 仅凭通用谱带或单点 EDS 定相 | "PO₄ 带对所有磷酸盐通用，无 XRD 不能定相。" |
| 模型体系外推 | 模拟样推至真实对象 | "试样为新生多孔压块，非风化层。" |
| 加速试验代表不足 | 单次冲刷 / 替代盐 | "单次 250 mL 冲刷，与长期酸雨场景不匹配。" |
| 时间尺度外推 | 短期数据解释长期现象 | "数据仅 180 d，论断解释的是 1900 年材料。" |
| 利益冲突 | 资助方 / 专利与结论同向 | "作者持三项相关专利，推广主张与其范围重合。" |
| 细节藏附录 | 正文缺关键参数 | "关键配比在 Table S1，正文未给，不可核验。" |
| 二手引用 | 关键论断引自转述 | "该论断引自 [7] 的转述，建议回溯原文。" |
| 术语误译 | 概念与量纲不符 | "`infinite` 应为 `unconfined`（无侧限）。" |

## 4. 单元拆分建议

- **按论证环节切，不按章节切。** Abstract + Introduction 通常可合并为"问题与缺口"。
- Related Work 若按主题分块（≥3 个主题），按主题拆。
- Method 常需拆分：问题形式化 / 架构 / 参数 / 实现细节。
- Results 按"设置 / 主结果 / 机制解释 / 稳健性"切；数据与紧随其后的解释同单元。
- Discussion + Limitations + Conclusion 可合并为"含义与边界"。
- Materials and Methods 通常独立成"可复现性"单元。
- 目标：每单元对应原文 2–4 页（普通排版），讲完 600–900 中文字；超限则拆。
